# Data Warehouse and Analytics Project

Welcome to the **Data Warehouse and Analytics Project** repository
This project will demonstrate a comprehensive application of data warehousing for purposes of data engineering and data analytics. This project will begin from building a data warehouse and finish with insights based on data housed within the data warehouse

## Project Requirements

### Building the Data Warehouse (Data Engineering)

#### Objective
Demonstrate knowledge of data and data preparation through the development of a bronze/silver/gold type data warehouse using SQL Server. This will enable the use of data analysis to generate reports and encourage informed decision-making

---

### BI: Analytics & Reporting (Data Analytics)

#### Objective
Showcase knowledge of SQL Server and Data Analytics by developing SQL-based analytics of data
